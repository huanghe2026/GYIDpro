## 部署完成：gyid.geoyuan.com（零 TCP 端口）

### 后端改造：trip-server 支持 Unix socket
- 新增 `trip-server/src/listen.rs`：`ListenTarget::{Tcp,Unix}` + `parse()`，支持 `TRIP_LISTEN=unix:/path`
- **踩坑**：axum 0.7.9 的 `axum::serve` 签名固定为 `serve(TcpListener, M)`，**没有**可插拔的 `Listener` trait（0.8 才有），`axum::serve::Listener` 根本不存在 → Unix 一路改为手动驱动 hyper 1.x（`hyper::server::conn::http1::Builder` + `service_fn` + `TokioIo`，必须 `.with_upgrades()` 否则 WebSocket 101 失败）
- 新增依赖：`hyper`(http1,server)、`hyper-util`(tokio)、`tower` 0.5；服务端 socket 残留会先探测再删除

### 前端改造：Astro 支持 base 子路径
- `astro.config.mjs` 读 `BASE_PATH` / `OUT_DIR`，一套源码出两个变体：
  - `OUT_DIR=./dist BASE_PATH=/ npm run build` → 站点根
  - `OUT_DIR=./dist-verify BASE_PATH=/verify/ npm run build` → 子目录
- `src/i18n/ui.ts` 的 `path()`、`Layout.astro` favicon、`lib/wasm.ts` 的 WASM 胶水层 URL 全部改为跟 `import.meta.env.BASE_URL`
- 新增 `src/pages/404.astro` + `src/components/pages/NotFound.astro`
  - **踩坑**：把 404 挂在 `[...slug]` 注册表里会产生两个后果 —— TS 把键 `404` 推断成 **number** 污染 `PageSlug`，且根级动态路由**产不出** `404/index.html`。必须用 Astro 原生 `src/pages/404.astro`（固定输出 `/404.html`）
  - **踩坑**：nginx `try_files $uri $uri/ =404` + `error_page 404 /404.html` 当目标文件**不存在**时会形成内部重定向环 → 返回 **500** 而不是 404
