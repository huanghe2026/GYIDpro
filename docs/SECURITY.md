## 安全设计原则

### 核心原则

GyID 遵循以下安全设计原则：

1. **本地计算优先** - 所有敏感数据处理在本地完成，不上传原始数据
2. **最小化收集** - 只收集必要的身份因子
3. **不可逆哈希** - 存储哈希而非原始数据
4. **去中心化** - 不依赖中心化认证机构
5. **可验证性** - 链上锚定提供不可否认性

## 数据采集安全

### 硬件指纹采集

| 数据源 | 权限要求 | 安全措施 |
|--------|----------|----------|
| MAC 地址 | 管理员 (Windows) | 仅采集哈希 |
| CPU ID | 管理员 (Windows) | 仅采集哈希 |
| 主板序列号 | 管理员 (Windows) | 仅采集哈希 |
| 磁盘序列号 | 普通用户 | 仅采集哈希 |

**安全措施**:
- 所有硬件数据直接进行 BLAKE3 哈希处理
- 不存储原始硬件信息
- 哈希值作为 GyID 生成因子之一

### 地理位置采集

| 精度等级 | 数据来源 | 隐私保护 |
|----------|----------|----------|
| L1 (城市级) | IP 定位 | 仅城市级精度 |
| L2 (区域级) | WiFi BSSID | 不记录具体位置 |
| L3 (精确级) | GPS | 用户授权后采集 |

**安全措施**:
- 用户可选择关闭位置信息
- 位置数据不存储原始坐标
- 仅使用 H3 网格作为间接因子

## 隐私保护机制

### 数据不上传

GyID 设计确保：

```
用户设备                          GyID 服务器
    |                                  |
    |-- 采集硬件指纹 --> 不采集原始硬件数据
    |-- 采集位置信息 --> 仅接收 H3 网格 ID
    |-- 采集头像哈希 --> 不存储头像图片
    |-- 生成 GyID -----> 接收最终 GyID
```

### 隐私保护特性

| 特性 | 说明 |
|------|------|
| 离线生成 | 无需网络连接即可生成 GyID |
| 无账号注册 | 不需要手机号、邮箱等个人信息 |
| 不可逆 | 哈希设计确保无法反推原始数据 |
| 可选位置 | 用户可禁用地理位置采集 |
| 无追踪 | 不使用 cookies 或追踪器 |

## 密码学安全

### 哈希算法

GyID 使用 **BLAKE3** 作为核心哈希算法：

```rust
// GyID 生成公式
GyID = Base58(BLAKE3(
    W1 * hardware_fingerprint XOR
    W2 * geo_hash XOR
    W3 * timestamp XOR
    W4 * avatar_hash XOR
    salt
))
```

**BLAKE3 优势**:
- 抗碰撞：密码学安全哈希
- 高性能：比 SHA-256 快 10 倍以上
- 跨平台：纯 Rust 实现，支持 WASM
- 可验证：广泛使用，经过审计

### 编码算法

| 算法 | 用途 | 安全性 |
|------|------|--------|
| Base58 | GyID 编码输出 | 无特殊安全需求 |
| hex | 内部调试 | 无特殊安全需求 |

### 时间戳保护

```rust
// 时间戳格式
timestamp = (UTC毫秒 << 16) | 16bit随机数
```

- **毫秒精度**：确保唯一性
- **随机数**：防止时间猜测攻击
- **16位扩展**：增加熵值

## 链上数据安全

### Polygon PoS 锚定

```
交易数据格式:
+--------------------------------+
| Magic: "gyid" (4字节)          |
| gyid_hash (32字节)             |
| metadata_hash (32字节)          |
+--------------------------------+
```

**安全措施**:
- 仅上传 GyID 哈希，不暴露原始 ID
- 交易 value = 0，不涉及资金转移
- 多 RPC 端点容错，防止单点故障

### Aptos 锚定

```
交易字段:
- sender: 账户地址
- memo: "gyid:" + gyid_hash
- value: 0.000001 APT (最小转账)
```

**安全措施**:
- 使用 ED25519 签名
- BCS 编码确保序列化一致性
- 仅记录哈希，不记录原始数据

### 私钥管理

```bash
# 私钥通过环境变量配置
export GYID_CHAIN_KEY="your_private_key_hex"
export GYID_APTOS_KEY="your_ed25519_key_hex"
```

**安全原则**:
- 私钥不写入任何文件
- 仅存储在环境变量中
- 建议使用硬件钱包管理私钥

## 抗攻击能力

### 抗伪造攻击

| 攻击类型 | 防护措施 |
|----------|----------|
| 硬件模拟 | 多维度硬件指纹组合 |
| 位置欺骗 | GPS + WiFi + IP 三重验证 |
| 重放攻击 | 时间戳 + 随机数 |
| 头像伪造 | 时间因子防止重复 |

### 抗追踪攻击

| 攻击类型 | 防护措施 |
|----------|----------|
| 行为追踪 | 无网络回传设计 |
| 指纹追踪 | 动态权重增加变化 |
| 位置追踪 | H3 网格提供粗粒度 |

### 抗暴力攻击

| 攻击类型 | 防护措施 |
|----------|----------|
| 哈希碰撞 | BLAKE3 抗碰撞性 |
| GyID 猜测 | 256 位哈希空间 |
| 时间猜测 | 16 位随机数扩展 |

## 安全建议

### 用户安全建议

1. **保护设备物理安全**
   - 启用设备加密
   - 设置强密码/生物识别

2. **谨慎使用位置信息**
   - 高隐私需求时使用 None 模式
   - 避免在敏感场所生成 GyID

3. **保护链上私钥**
   - 使用硬件钱包
   - 定期轮换私钥
   - 启用多签钱包

4. **头像选择**
   - 使用专用的 GyID 头像
   - 避免使用其他平台的头像

### 开发集成建议

1. **WASM 平台**
   - 验证 WebGL/Canvas 不可访问
   - 限制 fingerprint API 调用

2. **移动端**
   - 使用 KeyChain/Keystore 存储
   - 启用应用沙箱

3. **服务端验证**
   - 验证 GyID 格式
   - 检查链上锚定状态
   - 记录审计日志

## 已知限制

### 潜在风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| MAC 地址随机化 | 同一设备 GyID 变化 | 多因子组合降低影响 |
| VPN 使用 | 位置信息不准确 | 用户可选禁用位置 |
| 虚拟机检测 | 虚拟机环境 GyID 不同 | 设计允许 |
| 设备更换 | GyID 变化 | 设备关联功能 |

### 不适用场景

GyID 不适用于以下场景：

1. **需要找回功能的场景** - GyID 无遗忘保护
2. **需要中心化管理的场景** - 去中心化设计
3. **需要法律身份的验证** - 不提供 KYC 功能
4. **高频更换设备的用户** - 设备绑定身份
