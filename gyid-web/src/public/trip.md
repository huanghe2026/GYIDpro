# TRIP: Trajectory-based Recognition of Identity Proof
> 文档为IETF互联网草案：**draft-ayerbe-trip-protocol**，属于IETF RATS（远程证明流程）工作组的独立提交草案，**尚未成为正式RFC标准**，属于正在迭代的密码学+人类移动行为身份认证协议

## 一、撰稿人
1. **Camilo Ayerbe Posada（主作者）**，ULISSY s.r.l.（意大利罗马）
2. **M. Usama Sardar（第二作者）**，德累斯顿工业大学（TU Dresden，德国）

## 二、核心背景与起源历史
传统线上身份验证依赖证件、人脸、密码，存在单点隐私泄露、深度伪造、重放攻击、Sybil女巫攻击等缺陷。TRIP提出了一条完全不同的思路：**把人在现实世界持续的物理移动轨迹，作为“真人存在”的证明**。

理论根基来自两大基础研究：
1. 乔治·帕里西（Giorgio Parisi，诺贝尔物理奖）关于生物系统无标度关联、自组织临界（SOC）的研究；
2. 巴拉巴西（Albert-László Barabási）团队对人类移动模式的研究：人类位移服从截断莱维飞行（Truncated Lévy flights），具备独特的1/f粉红噪声功率谱密度（PSD）特征，机器/脚本伪造的轨迹很难复现该统计特征。

TRIP协议把手机GNSS、IMU传感器采集的时空位置，经过H3六边形空间量化，生成加密签名的轨迹片段（breadcrumb，面包屑），形成只保留统计特征、**不上传原始GPS坐标**的隐私保护证明链，输出「人类存在证明证书PoH Certificate」与轨迹身份令牌TIT（Trajectory Identity Token），用于匿名伪身份认证。

## 三、时间线（IETF草案版本迭代）
1. **-01版本（2026年初）**：首次提交IETF草案，引入Criticality Engine（临界引擎），将帕里西、巴拉巴西的统计物理模型作为核心判别引擎，区分生物移动与合成伪造轨迹。
2. **-02版本（2026-02-09）**：正式映射到RATS架构（RFC9334）；新增主动验证协议（Active Verification Protocol），修复隐私模型；此时仍保留被动验证模式。
3. **-03版本（2026-05-07）**：统计物理学专家评审后的重大修订：
    - 将非正式术语“Parisi因子”改为标准谱分析术语**PSD缩放指数α**；
    - 补齐莱维飞行指数β与PSD α之间数学推导；
    - 增加收敛分析，给出可靠身份判定所需最小轨迹采样点数；
    - **彻底删除被动验证模式**，所有证明必须绑定依赖方nonce，杜绝证书重放攻击。
4. **-04版本（2026-05-08，当前最新版）**：补充附录，横向对比EAT位置声明、Proximate Location、可验证地理围栏、PoP位置证明等其他IETF位置证明方案；完善编辑勘误；文档有效期至2026-11-09，到期后需要更新或废止。

> 注意：TRIP**不是成熟商用标准**，属于IETF互联网草案（Internet-Draft），仅为技术规范草稿，随时可能修改、废弃，不具备正式RFC效力。

## 四、现状
1. **标准化状态**：IETF RATS工作组内讨论中的独立提交草案，**尚未投票发布RFC**，属于研究性协议，暂无大规模生产级部署。
2. **协议定位**：传输无关，不绑定特定区块链、域名系统，可独立运行；遵循RATS远程证明模型：证明方（手机）、验证方（Criticality Engine）、依赖方（业务服务）。
3. **隐私设计要点**
    - 原始GPS坐标在设备本地使用H3网格量化，不可逆有损压缩，**原始坐标不会外传**；
    - 最终对外交付的PoH证书**只输出统计参数（α、β、可信度分数），不含地理位置信息**；
    - 支持多独立验证方，依赖方可自行选择信任的验证节点。
4. **局限与待解决问题**
    - 机器人/无人机搭载手机模拟真实GPS+IMU信号，属于最难防御的攻击，仍在研究；
    - 轨迹判定需要足够样本：至少200条breadcrumb才能得到高置信度判定；短轨迹容易误判；
    - 针对行动不便、长期静止的用户，协议内置了适配方案，不强制要求空间移动，依靠时序连续性做评估；
    - 没有内置人名绑定，输出的是**伪匿名身份令牌TIT**，不直接关联现实身份。

## 五、应用案例（草案描述的预期应用场景，**公开大规模落地案例极少，多为设想场景**）
1. **Web3/去中心化身份DID与人类证明（Proof-of-Humanity）**
    去中心化社区、DAO、链上投票、空投防女巫攻击。不用上传证件、人脸，依靠长期真实移动轨迹证明账户背后是真人，防止批量机器人刷号。
2. **远程在线服务的持续活体核验**
    远程考试、远程劳务平台、自由职业者平台。传统人脸核验只是单点快照；TRIP提供**跨时间持续物理存在证据**，检测账号是否被代持、换人登录。
3. **高风险线上账号的身份连续性认证**
    金融、数字政务辅助身份校验，作为第二因子，不替代证件，用于辅助判断“长期操作该账号的是同一个实体”，防范身份劫持。
4. **隐私优先的地理可信服务**
    位置证明类业务（如本地商户权益、区域访问权限），不需要提交精确GPS，仅证明该身份在一段时间内真实在该区域活动，保护用户位置隐私。
5. **物联网/车联网实体行为校验**
    区分自动驾驶设备和人类操作者轨迹，用于车联网Sybil攻击检测。

> 重要区分：TRIP**不是一次性位置证明**，它的核心卖点是**时序连续的移动行为统计证明**，和IETF其他单点位置证明协议互为补充，而不是替代关系。
